# Screenshots

PNG files in this directory are the application screenshots embedded in
[README.md](../../README.md) / [README.en.md](../../README.en.md).

They are generated by [`tests/webdriver/screenshots.ts`](../../tests/webdriver/screenshots.ts)
in CI (the `app-screenshots` artifact of the *WebDriver smoke* workflow), not
drawn by hand:

1. Download the artifact, e.g. `gh run download <run-id> -n app-screenshots`.
2. Unzip it here and review the images.
3. Commit the good ones — CI never commits screenshots itself.

The full refresh procedure is described in
[docs/testing.md](../testing.md) ("Capturing README screenshots").
